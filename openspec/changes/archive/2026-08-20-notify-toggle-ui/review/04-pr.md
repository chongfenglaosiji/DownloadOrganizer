### 发现/备注

- **（环境，非缺陷）CI 缺失**：`build.yml` 仅 tag 推送触发，PR 阶段无 workflow 运行（check-runs 空）——属仓库 CI 设计，非本 PR 问题；全量测试与 ruff 的机器级验证在合并前不可得，已由 #1/#2 显式报告。

- **（观察）GUI 保存与运行时开关不同步**：GUI 保存只写 TOML、不更新运行时开关，与"重启后生效"提示（gui.py L297）及 spec"重新加载配置后"措辞一致，前序 review 已记录为非缺陷。
